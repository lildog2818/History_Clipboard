# 剪贴板历史（轻量版）

一个类似 Ditto、但更轻量简洁的 Windows 剪贴板历史工具。纯原生 C# / .NET 8 + WPF 实现，**零第三方 NuGet 依赖**（仅 .NET BCL + Win32 P/Invoke）。

## 功能

- 后台常驻（托盘图标），实时记录剪贴板历史：纯文本、HTML/富文本（CF_HTML + CF_RTF）、图片、文件列表。
- 全局热键唤起悬浮搜索条，毛玻璃质感（Win11 Mica / Win10 亚克力），黑白双主题（跟随系统/手动切换）。
- 窗口可拖动、可缩放、可最大化，带关闭/设置按钮。
- 搜索/过滤（命中高亮）、置顶/收藏、条目备注与标签、粘贴为纯文本、删除/清空、内容预览面板。
- 三页签（文字 / 图片 / 文件）：图片页为自适应两端对齐网格，按图片原始宽高比完整显示（不裁切变形），行高随窗口大小自适应——小窗约两列，全屏一屏可览多张。双击图片直接贴图。
- 单击条目查看（预览面板底部显示备注、时间、来源），双击粘贴；窗口位置/大小自动记忆。
- Snipaste 式截图与贴图：区域截图，截后可「复制 / 贴图 / 取消」，截图自动入库。
- 应用内复制（复制条目文字、复制图片、粘贴时的剪贴板写入）不会重复入库。
- 可视化设置：快捷键、主题、保存目录、条数上限、纯文本模式、排除应用、开机自启。
- 删除即彻底删除：条目与对应图片文件立即物理移除（不进回收站），并同步写盘，不会"复活"。
- 开机自启、单实例（重复启动自动唤起搜索条）。

## 默认快捷键

| 快捷键 | 功能 |
| --- | --- |
| `Ctrl + \``（反引号） | 唤起/关闭搜索条 |
| `Ctrl + Alt + A` | 区域截图 |

> 两个快捷键均可在「设置」中修改。

搜索条内：

| 按键 | 功能 |
| --- | --- |
| 单击条目 | 选中并预览（不粘贴） |
| 双击条目 | 粘贴（图片条目为「贴图」） |
| `↑` / `↓` | 选择条目 |
| `Enter` | 粘贴（保留格式） |
| `Ctrl + Enter` 或 `Shift + Enter` | 粘贴为纯文本 |
| `Ctrl + 1` / `2` / `3` | 切换 文字 / 图片 / 文件 页 |
| `1` - `9` | 快速粘贴第 N 条（列表获焦时） |
| `Ctrl + C` | 复制选中文字 / 复制图片 |
| `Ctrl + P` | 置顶 / 取消置顶 |
| `F2` | 编辑备注与标签 |
| `Del` | 删除 |
| `Esc` | 关闭 |
| 右键条目 | 更多操作（复制、贴图、置顶、备注、删除） |

贴图窗口：拖动移动、滚轮缩放、双击或 `Esc` 或右上角按钮关闭、右键复制/关闭/全部关闭。

## 设置

托盘菜单或搜索条右上角齿轮按钮打开「设置」：

- **快捷键**：唤起搜索、截图（按下组合键即可录入）。
- **外观**：跟随系统 / 浅色 / 深色。
- **存储**：保存目录（可迁移）、历史条数上限（默认仅手动清理，可设上限自动裁剪最旧非置顶条目）。
- **行为**：粘贴后还原剪贴板、`1-9` 快速粘贴、仅记录纯文本（不存富文本格式）。
- **隐私**：排除应用（不记录指定进程的复制内容，如密码管理器）。
- **常规**：开机自启。

## 运行要求

- Windows 10 1809+ 或 Windows 11（Mica 效果仅 Win11，其余自动回退亚克力/纯色）。
- 默认构建为**框架依赖**单文件（约 0.2 MB），需要安装 [.NET 8 Desktop Runtime](https://dotnet.microsoft.com/download/dotnet/8.0)（未安装时系统会提示并引导下载）。

## 数据存储

- 默认目录：`%LOCALAPPDATA%\ClipboardHistory\`（`history.json` + `images\`）。
- 可在「设置」中更改，历史会自动迁移到新目录。

## 构建与发布

```powershell
# 框架依赖（极小体积，约 0.2 MB，需 .NET 8 Desktop Runtime）
dotnet publish ClipboardHistory.csproj -c Release -r win-x64 --self-contained false -p:PublishSingleFile=true -o publish

# 自包含（免运行时，体积更大）
dotnet publish ClipboardHistory.csproj -c Release -r win-x64 --self-contained true -p:PublishSingleFile=true -o publish
```

## 已知限制

- 无法向「以管理员身份运行」的窗口粘贴（Windows UIPI 隔离，暂未做提权辅助进程）。
- 截图在「混合 DPI 多显示器」下可能坐标偏移（单一显示器或统一缩放不受影响）。
- 贴图仅保留核心操作（拖动/缩放/关闭/复制），Snipaste 的旋转、取色、马赛克、鼠标穿透等高级功能未包含。
